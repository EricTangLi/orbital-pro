### 验收（每条都要真实输出）

- [x] **新增字段必须有写入路径**（2026-11-12 补，ADR-031 教训）：每个 `CREATE TABLE` 的列，同一里程碑内必须有代码写它；

- [x] `cargo test` 全绿，且测试数 ≥ 40
- [x] **进程隔离实测**：`taskkill` 掉 core 进程 → GUI 仍可响应、proxy 仍可转发（或明确降级日志）→ 启动器自动重启 core

- [x] **写入回查 100/100**：随机写 100 条，逐条用返回的 id 查回，0 失败
- [x] **伪造身份 403**：以 `agent=dsh` 的进程声明 `agent=hermes` 写入 → 拒绝且库内 0 行
- [x] **旧库拒绝服务**：用 schema 版本不符的库启动 → 明确报错并保留数据
- [x] **4/4 接入 + detach**：每个 agent 都返回一条真实记忆 id；`--detach` 后**配置里不再有 orbital 条目**（restore 用备份覆盖后 sha256 与备份一致）—— 实测 WorkBuddy：detach 后条目消失且 JSON 合法，恢复后 sha256 `b840dc32…` 完全一致
- [x] 安装包能在**本机干净目录**完成安装并启动（不是 `cargo run`）
- [x] 真机截图：三进程状态页（真实数据，不是 mock）
- [x] **只有一个 exe 文件**：安装目录里 `OrbitalPro.exe` 一个可执行文件；`Get-Process OrbitalPro` 能看到 **3 个进程**（`--role core/proxy` 各一 + GUI）
- [x] **关闭窗口不退出**：点 X 后进程仍在，托盘图标还在；再从托盘「打开」能回到窗口
- [x] **托盘「退出」真退出**：3 个进程全部消失
- [x] **单实例**：连点两次 exe，只有 1 个托盘图标 + 1 个窗口，且第二次会聚焦

## 11 计划体系与门禁（**每次开工/收工都要走**）

### 11.1 三层文件

| 层 | 文件 | 作用 | 谁读 |
|---|---|---|---|
| **仪表盘** | `PLAN.md`（根目录） | 现在在哪、下一步、进度总表 | **每次必读** |
| **任务卡** | `plans/M<N>-详细任务卡.md`、`plans/M0-…` | 每个任务的 8 节：需求/必读文档/技术方案/功能点/验收/风险/待确认/执行记录 | 做该任务时必读 |
| **设计规格** | `docs/00-11` | 需求与方案的权威来源 | 按任务卡里的"必读文档"读 |

### 11.2 开工前五步（缺一步不许写业务代码）

1. 读 `PLAN.md` 的「当前任务」；
2. 读该任务卡全文，**逐份读完**卡里列的必读文档（并在卡上打勾）；
3. 确认任务卡的「待确认问题」为空——**有未决问题就去调研，调研不了就问用户，不许猜**；
4. 跑门禁：`powershell -NoProfile -File scripts/check-plan.ps1` → 必须 **PASS**；
5. 登记 AWO-Task（`DP-TECH`），把任务卡的验收项抄进 `acceptance`。

### 11.3 收工四步

1. 在任务卡的「执行记录」追加：日期 / 做了什么 / 验证输出 / remaining / 下一步；
2. **设计对比验证**（用户 2026-11-12 明确要求）：把本任务涉及的**每一条设计约束**与代码逐条对照，
   在「执行记录」里写对比表（约束 / 代码位置 / 判定：一致·偏差已修·未到任务）；
   **有偏差必须先修**，不许带着偏差进入下一个任务；
3. 更新 `PLAN.md`：当前进度、当前任务、最近更新日期；
4. `CHANGELOG.md` 追一条；再跑一次 `check-plan` 确认没有把门禁改坏。

### 11.4 门禁脚本能拦什么（本机实测）

```text
check-plan.ps1   → 计划纪律：任务卡是否存在、8 节是否齐、待确认是否清空、文档闸门
check-docs.ps1   → 文档纪律：必读文档存在、交叉引用无死链、废弃术语（按语境判断）
```

**实测对照（2026-11-12）**：
- 当前任务 `T-M0-01` 留有 1 条"待确认（等用户签字）" → `CHECK-PLAN: FAIL (1 项) —— 不许开工`，`exit 1`
- 指定合格任务 `T-M1-00` → `CHECK-PLAN: PASS —— 可以开工`，`exit 0`
⇒ 门禁**能红能绿**，不是装饰。

| 节 | 防什么 |
|---|---|
