# 项目章程（v1.0）

> 这份文档回答三个问题：**这是什么、边界在哪、谁说了算。**
> 所有其他文档都受本文约束。

---

## 1 一句话

> **Orbital Pro 是一个 Windows 独立桌面应用：让一台电脑上的所有 AI agent 共用一套可信的记忆——记得住、找得到、管得动、忘得掉。**

四个动词缺一不可：
- **记得住**：多 agent 写进同一个库，归属清楚
- **找得到**：语义 + 关键词 + 图关系 + 结构化过滤
- **管得动**：查看 / 编辑 / 合并 / 建关系 / 退役（**操作台，不是看板**）
- **忘得掉**：按有效重要度衰减，可逆退役

## 2 边界

### 2.1 做什么

| 层 | 内容 |
|---|---|
| 存储 | SQLite（bundled）+ 三通道（文本 / 结构化属性 / 图关系） |
| 接入 | MCP（7 工具）+ Proxy（三协议注入） |
| 治理 | 体检、冲突、重复合并、退役、审计 |
| 界面 | 五页：Agent 详情 / 记忆 / 维护 / 设置 / 状态 |
| 交付 | 安装包 + 首启引导 + 托盘常驻 |

### 2.2 明确不做

| 不做 | 理由 |
|---|---|
| 自研向量库 / embedding 模型 | 用端点（云 API / Ollama / FTS5 兜底） |
| 团队 / 多租户 / ACL | 单用户单机场景 |
| 通用 agent 适配器（支持 12+ 工具） | 只服务本机 4 个 + 按需扩展 |
| 复用 mnemon / TencentDB 的代码 | 只参考设计（见 ADR-001） |
| 云端同步 / 跨设备 | 本地优先，数据不出机器 |
| 做成"看板" | 铁律：操作台 |

## 2.3 竞品定位（2026-11-12 代码级调研后更新）

| 竞品 | 它已有什么 | 它没有的 | 对我们的含义 |
|---|---|---|---|
| **CC Switch**（153k★，本机 v4.0.25） | 多 agent 配置切换（`AppType` 已含 **Dsh / Hermes / Pi**）、模型/provider 配置、托盘常驻、单实例、备份回滚 | **跨 agent 统一记忆层**（全仓 `memory` 只出现在 Hermes 的配置页） | **"接入 + 模型配置"不是空白市场**，只是必要能力，不是卖点 |
| dsh-mnemon（本机 0.5.42） | 记忆工具面、多 provider 编排、上下文预算闸门 | 独立 GUI、跨 agent 归属、操作台 | 借它的工具面与预算设计，不做它的 DSH 插件形态 |
| TencentDB-Agent-Memory | 分层、四维隔离、操作台 | Windows 独立安装（要 Docker）、写入链路身份贯通 | 借隔离与诊断设计 |

⇒ **差异化只有一个：记忆**。产品竞争力压在"跨 4 个 agent 的记忆统一、可检索、可治理、可注入"，而不是"能配几家 agent"。
**纪律**：任何人提议把"接入更多 agent / 支持更多模型厂商"当卖点，一律先读本节。

## 3 与旧项目的关系

| 项目 | 状态 | 说明 |
|---|---|---|
| `../agent-memory-hub`（旧 Orbital） | **测试项目**（保留） | W1–W11 已实现，142 项测试；但其 schema 只有单通道、UI 是看板式、进程模型违反约束 |
| **本项目** | 正式产品 | 数据模型/架构/UI 全部重做；**只移植已验证模块**（writer 队列、proxy 三协议、agent attach 原子写） |

**迁移原则**：不整体继承。旧代码只有在"有测试 + 与 `docs/04` 不冲突"时才可移植，且移植后必须重跑本项目测试。

| 里程碑 | 门禁 | 详细 |
|:--:|---|---|
| M0 设计冻结 | 用户签字 | `docs/05` |

## 6 成功定义（怎么算这个项目成了）

1. 用户能在一台**没有本机配置**的 Windows 上安装、接入 1 个 agent、写入并查回一条记忆；
2. 8 个 JTBD 中 **≥7 个**能在 GUI 独立完成（不需要命令行）——**目标落在 M6**（M2 门禁只承诺 5 条，ADR-039）；
3. 写入 100 条，回查 **100/100**；跨 agent 对抗查询 **0 泄漏**；
4. 召回质量有**基线**，每次改动有前后对照；
5. 没有任何"自动硬删"路径。

## 7 风险 TOP 5

| # | 风险 | 影响 | 缓解 |
|:--:|---|---|---|
| 1 | **UI 再次被判定"业余"** | 全盘返工 | M0 冻结 token；每次界面改真机截图 1:1 对照；大改先给设计稿 |
| 2 | **三进程在 Tauri 里不稳定** | 核心体验崩 | M1 先做 spike（spawn/杀/重启），不通就重新评估 |
| 3 | **召回质量无法证明** | "记得好"变成口号 | M3 先建基线，再做优化 |
| 4 | **范围膨胀**（想支持所有 agent） | 永远做不完 | 只服务 4 个 agent；Non-goals 清单 |
| 5 | **AI 协作跑偏**（改了设计不报告） | 反复返工 | `AGENTS.md` 红线 + 三件套 + 阶段门 |
