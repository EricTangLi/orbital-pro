# 用户指南 · Orbital Pro

> 这份文档是给**第一次用**的人看的。不需要懂技术，按步骤做就行。
> 遇到不懂的词，看每节末尾的「术语」小注。

---

## 1 它是什么

**Orbital Pro（忆核）是一个"记忆中枢"**：把你的 AI 助手们说过的重要事情记下来，
下次开新对话时它们还能想起来。

举个实际例子：

| 没有它 | 有它 |
|---|---|
| 你告诉 Hermes"我们项目用 8790 端口"，换成 pi 问同样的事，它不知道 | 两个助手都能查到这条约定 |
| 上周讨论过的方案，今天新开对话全忘了 | 开场就带着"上次做到哪、不要碰什么" |

**一句话**：让 AI 助手记住你，而不是每次都从零开始。

---

## 2 安装

1. 双击 `Orbital Pro_x.x.x_x64-setup.exe`
2. Windows 会提示"未知发布者"——这是正常的（还没买代码签名证书），点「仍要运行」
3. 装完会自动启动，托盘区出现一个图标

> **术语**：**托盘** = 屏幕右下角那排小图标（时钟旁边）。
> **代码签名证书** = 一种"出版身份证"，买了 Windows 才不会报"未知发布者"。个人用不买也行。

---

## 3 第一次打开

主界面左边是**导航**，从上到下：

| 页面 | 干什么 |
|---|---|
| 概览 | 看总量、近 7 天写入、体检分数 |
| 记忆 | 所有记忆的列表（搜索、筛选、编辑、删除） |
| 退役 | 不再用但还没删的（可恢复） |
| 连接 | 管理 agent 的接入方式 |
| 维护 | 待办（缺向量、重复、未打标签…） |
| 状态 | 服务健康、注入统计 |
| 设置 | 一键接入、备份、诊断包 |

**第一次进来先做一件事**：去「设置」→「记忆注入接入」，把你要用的 agent 打开。

---

## 4 让 agent 用上记忆（一键接入）

「设置」→「**记忆注入接入**」有四个 agent：

| agent | 怎么接 |
|---|---|
| **WorkBuddy** | 点「一键部署」→ 它会写一个受控区块到 MEMORY.md |
| **Hermes** | 点「一键部署」→ 写脚本 + 注册 hook |
| **pi** | 点「一键部署」→ 写扩展文件（之后在 pi 里 `/reload`） |
| **DSH** | 点「一键部署」→ 装插件（之后**重启 DSH**） |

**接完怎么确认？** 点每行的「**自检**」——底部弹出「召回 N 条」就是通了。

> **术语**：**注入** = 每次对话自动把相关记忆"顺带"发给 agent（不用你手动问）。
> **hook / 插件 / 扩展** = 各家 agent 提供的"外挂入口"，名字不同但作用一样。

**注意**：
- 每家的部署/移除都**可恢复**（移除只清配置或改名，不删你的数据）
- WorkBuddy 只能看到 3 行索引（它的 MEMORY.md 有 4000 字硬限制）——要看全文用「记忆」页或 MCP

---

## 5 怎么"写"记忆

三种方式：

| 方式 | 适合 |
|---|---|
| **在 agent 里直接说** | "记住：我们项目用 8790 端口" —— agent 会调 MCP 存进去 |
| **在「记忆」页手动新建** | 想自己整理 |
| **自动沉淀** | 有些 agent 会自己判断"这条值得记" |

**写的时候选「共享」还是「私有」**：
- **私有**：只有你自己（当前 agent）看得到
- **共享**：所有 agent 都能看到（跨 agent 协作时用）

> 已存的私有记忆可以在「记忆」页点「**提升为共享**」改成共享。

---

## 6 怎么"召回"

**会自动召回**：接好之后，每次对话自动带上相关记忆（你看不到，但 agent 看得到）。

**手动查**：
- 在「记忆」页搜索框输入关键词
- 或在 agent 里说"帮我查一下关于 X 的记忆"

> **术语**：**召回** = 从记忆库里"找出来"。
> **三种找法**：关键词（字面匹配）+ 向量（意思相近）+ 图（有关系的）——三路结果合并排序。

---

## 7 怎么"忘掉"

| 想要 | 操作 |
|---|---|
| 暂时不用（可恢复） | 「记忆」页 → 删除 → 软删（进「退役」页） |
| 永久删 | 「退役」页 → 彻底删除（不可恢复） |
| 标记过期 | 详情页 → 失效（保留记录，不再被召回） |

**建议**：先软删，过几天确认没用再彻底删。

---

## 8 备份与恢复

「设置」→「数据与备份」：

- **立即备份**：生成一份快照（含数据库 + 索引）
- **校验**：检查备份是否完整
- **恢复**：从快照还原（**会覆盖当前数据**，需输入「恢复」二次确认）

**数据在哪**：`%LOCALAPPDATA%\OrbitalPro`（**卸载不会删**）——所以重装后数据还在。

> ⚠️ 注意两个目录**只差一个空格**：
> `Orbital Pro`（程序）和 `OrbitalPro`（你的数据）。

## 9 常见问题

**Q：agent 说"没有记忆"，但我在记忆页看到了？**
A：先看「设置」→「记忆注入接入」里那家是不是「已部署」，再点「自检」。
如果自检显示「召回 0 条」，可能是这条记忆是**私有**的、而当前 agent 看不到——把它「提升为共享」。

**Q：注入的内容为什么被截断了（后面是 `…`）？**
A：注入是**索引级**的（每条 ≤220 字符、总共 ≤1200 字符），故意的——避免占满上下文。
要看全文，去「记忆」页或让 agent 调 MCP 查。

**Q：改了配置要重启吗？**
A：要。面板的「保存并重启 proxy」会自己重启；但**接入类**（DSH 插件 / pi 扩展）需要重启对应的 agent 本体。

**Q：会不会把我的隐私发到网上？**
A：嵌入（把文字变成向量）默认调用云端 API（SiliconFlow）；也可以改成**本机 Ollama**（不联网）。
在 `~\.orbital\secrets.json` 里配置端点。**记忆内容本身**存在本机 SQLite，不上传。

**Q：卸载会删我的记忆吗？**
A：**不会**。程序在 `Orbital Pro`，数据在 `OrbitalPro`，卸载只删前者。

## 10 一页速查

```
装 → 打开 → 设置 → 记忆注入接入 → 四家点"一键部署"
     → 每家点"自检"看到"召回 N 条" = 成功
     → 回 agent 里正常聊，它会自动带上记忆
```
