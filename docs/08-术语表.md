# 术语表（v1.0）

> 目的：同一概念只有一个名字。代码、文档、UI 文案、API 字段必须一致。
> 规则：新增术语先加到这里，再在别处使用。

---

## 1 核心概念

| 术语 | 英文/字段 | 定义 | 不许叫 |
|---|---|---|---|
| **记忆条目** | `memory` / `memories` | 一条持久化记忆，含内容、归属、时间语义 | "记录""数据行""笔记" |
| **记忆系统** | Memory System | 包含存储、检索、注入、治理的完整系统 | "记忆库"（那只是存储部分） |
| **记忆库** | Memory Store / DB | 仅指持久化存储层 | — |
| **记忆治理** | Governed Memory | 谁能写、写成什么类型、谁能看、何时失效 | "记忆管理"（太泛） |
| **作用域** | `scope` | `private` / `shared` / `entity` 三档可见范围 | "权限""可见性" |
| **归属 agent** | `agent` | 写入该记忆的 agent 标识（`dsh`/`hermes`/`pi`/`workbuddy`） | "来源"（来源是 origin） |

## 2 数据模型

| 术语 | 字段 | 定义 | 注意 |
|---|---|---|---|
| **自由文本通道** | `memories.content` | 一段自然语言 | 不能被过滤/排序 |
| **结构化属性通道** | `memory_facts` | 实体 + 属性 + 值 | 可过滤、可冲突检测 |
| **图关系通道** | `edges` | 记忆之间的有向关系 | 支持图扩展召回 |
| **实体** | `entity_type` + `entity_id` | 人/项目/工具/配置项等稳定标识 | 不是"标签" |
| **属性** | `property` / `value` | 实体的某个具体属性及值 | 不是"元数据" |
| **边类型** | `edge_type` | `temporal` / `semantic` / `causal` / `entity` | 只有这四种 |
| **双时态** | `valid_from/valid_to` + `recorded_at` | 事实有效时间 + 记录时间 | 两者不是一回事 |
| **有效重要度** | `effective_importance` | 按时间衰减与访问频率计算后的权重 | 不等于 `importance` |
| **内容指纹** | `content_hash` | 内容哈希，用于去重 | 不是文件哈希 |

## 3 行为

| 术语 | 定义 | 容易混淆 |
|---|---|---|
| **召回** | 按查询取回相关记忆（recall） | 不是"搜索"（搜索是 GUI 行为） |
| **注入** | 把召回结果塞进 LLM 请求（inject） | 不是"同步" |
| **预算** | 注入的条数/token 上限，必须从配置读 | 不是"限制" |
| **会话缓存** | 同一会话内复用召回结果 | 不是"缓存层"（那是架构层名） |
| **降权** | 降低召回排序权重 | 不是删除 |
| **退役** | 进入"待退役"状态，等人确认 | 不是删除 |
| **失效** | 设 `valid_to`，保留历史但不再召回 | 不是删除 |
| **软删** | 标记删除，可恢复 | 不是"隐藏" |
| **硬删** | 物理删除，只有人手动执行 | — |

## 4 失败与防护

| 术语 | 定义 | 判据 |
|---|---|---|
| **静默失败** | 接口返回成功但事实没落库 | 写入后必须能按 id 查回 |
| **串味** | A 的记忆被 B 看到/写到 | 对抗查询 0 命中 |
| **假绿** | 检查通过但实际没生效 | 必须有红绿对照（撤掉修复会失败） |
| **门控** | SQL 层的强制过滤条件 | 不是应用层过滤 |
| **一致性** | 多 agent 并发写同一实体时的裁决规则 | 后写胜 + 保留历史 |

## 5 产品与设计

| 术语 | 定义 | 不许叫 |
|---|---|---|
| **操作台** | Control Panel：能查看 + 能操作 | "看板""Dashboard""驾驶舱" |
| **JTBD** | Jobs To Be Done：用户要完成的任务 | "需求""功能点" |
| **影响面** | 删除/合并前显示的受牵连条目数 | "警告" |
| **三层披露** | 索引 → 时间线 → 详情 | "分级显示" |
| **设计 token** | 字号/字重/间距/圆角/颜色的唯一来源 | "样式变量" |
| **里程碑** | M0–M6，每个有门禁 | "阶段""版本" |

## 6 工程

| 术语 | 定义 |
|---|---|
| **ADR** | 架构决策记录（`docs/07`），含被否方案 |
| **DoD** | 完成定义：什么样的证据才算完成 |
| **RRF** | Reciprocal Rank Fusion，多路召回融合排序 |
| **基线** | 可重跑的测量结果，用于前后对照 |
| **写作用域** | 一个任务允许修改的文件范围 |

## 7 命名约定

- 文档：`NN-中文名.md`，NN 两位数字，**不复用编号**
- 代码 crate：`orbital-*`
- 环境变量：`ORBITAL_*`
- 错误码：`SCREAMING_SNAKE`（如 `AGENT_IDENTITY_MISMATCH`）
- API 字段：`snake_case`
- UI 文案：中文，标题不加句号
