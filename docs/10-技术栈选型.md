# 技术栈选型（v1.0 · 2026-11-12）

> 原则：**框架、组件、图标、图表一律用成熟开源方案，不自己写**（用户明确要求）。
> 方法：GitHub API + npm registry + 包内类型定义逐条核对；每个结论带来源与日期。
> 证据：`research/evidence/06-UI选型-2026-11.md`（48 KB，53 处来源 URL）。
> 本文是**唯一选型依据**；`AGENTS.md` 红线 4「不要引入新 UI 库」指"不许绕过本文另加"。

## 0 一句话推荐

| 层 | 选谁 | 一句话理由 |
|---|---|---|
| 桌面壳 | **Tauri 2**（crate 2.12.5 / CLI 2.12.4） | 单 exe 49.9 MB 的 CC Switch 就是它；WebView2 复用系统，包体积与内存远小于 Electron |
| 前端 | **React 19.3.1** + **Vite 8.3.8** + **TypeScript 7.0.2**（保守可退 6.0.3） | 与组件生态完全对齐 |
| 样式 | **Tailwind CSS 4.3.5**（CSS-first `@theme`） | token 单一来源，与 shadcn 配套 |
| 组件 | **shadcn/ui 4.23.0**，底座选 **Base UI**（新包名 `@base-ui/react` 1.9.0） | 官方 8 个 style、三底座可选；组件是"你的代码"，可像素级改 |
| 图标 | **lucide-react 1.72.0**（ISC） | 周下载 1.31 亿；单一线性风格，与 Linear 风格一致 |
| 图表（通用） | **recharts 3.10.1**（MIT，经 shadcn `chart` 封装） | shadcn 官方图表就是它，不额外引一层抽象 |
| 图表（**关系图**） | **Cytoscape.js 3.35.0**（MIT） | recharts **没有**力导向/网络图（见 §4 证伪），Cytoscape 是本职 |
| 动效 | **motion 14.12.0**（MIT）+ `@formkit/auto-animate` 0.10.2 | 布局过渡与列表增删各司其职 |
| 字体 | **Inter Variable** 5.3.0 + **JetBrains Mono** 5.3.0（`@fontsource-variable/*`） | 内置打包，不依赖网络字体 |

**体积账**（min+gzip，来自 06 实测）：recharts 146.4 KB + Cytoscape 130.6 KB = **277 KB**；
对比"ECharts 一把梭" **359.3 KB** ⇒ 拆开反而更省，且关系图能力更强。

## 1 桌面壳：Tauri 2（不是 Electron）

| 项 | 决策 | 依据 |
|---|---|---|
| 版本 | **crate `tauri` 2.12.5 / `@tauri-apps/cli` 2.12.4** | 06 实测 npm/GitHub |
| 不用 3.x | 3.0 仍是 alpha | — |
| 不用 Electron | 包 80–150 MB、内存 150–300 MB；我们不需要它的插件体系 | 旧项目实测 + 06 复核 |
| 需要的 feature | `tray-icon`、`protocol-asset`、`image-png` | 托盘与图标 |
| 插件 | `single-instance`、`window-state`、`updater`、`store`、`dialog`、`opener`、`log`、`deep-link`、`positioner`、`autostart`（或 `auto-launch` crate） | CC Switch 同款组合 |

**Tauri vs Electron 的诚实边界**：双方官方都**没有**内存/体积基准；第三方数字互相矛盾。
`research/evidence/06 §9` 因此**拒绝给数**，只保留机制差异（WebView2 复用 vs 自带 Chromium）。
我们的判据是**本机实测**：CC Switch（Tauri）单 exe 49.9 MB；M1 结束后用同一体积口径量我们自己。

**已知风险（必须登记）**：无边框标题栏在 Windows 11 拿不到 Snap Layouts（Tauri issue #4531 仍 open）⇒ **M1 默认保留系统标题栏**，不做自绘。

## 2 组件：shadcn/ui 4.23.0 + Base UI 底座

### 2.1 底座与包名（这一条最容易装错）

- shadcn 官方 2026-10 changelog 的原文是 "Trace and Code Block are available for **Base UI, React Aria and Radix** across all eight styles" ⇒ **三底座可选**，不是"已经换成 Base UI"。
- **新包名**：`@base-ui/react` **1.9.0**（2026-10-09 稳定）。
- **旧包名** `@base-ui-components/react` **冻结在 1.0.0-rc.0（2025-12-04）**——装旧名就等于用 rc。
- 初始化：`npx shadcn@4.23 init`，preset 选 **Base UI**；`components.json` 的 `style` 与 `baseColor` **初始化后不可改**（选错要删了重装）。

### 2.2 组件映射（界面元素 → 组件 → 底座）

| 界面元素 | 用哪个 | 说明 |
|---|---|---|
| 侧边栏 | shadcn `sidebar` | 官方组件，**不要自己撸** |
| 列表/详情双栏 | shadcn `resizable`（react-resizable-panels） | 记忆页主从布局 |
| 命令面板 `Ctrl+K` | shadcn `command`（cmdk） | 跳页/执行动作 |
| 设置分组 | shadcn `field` + `label` + `switch` + `select` | 6 组 × Row 版式 |
| 确认破坏性操作 | `alert-dialog` | 删除/合并/断开 |
| 提示 | `sonner`（shadcn 支持） | 比自建 toast 省事 |
| 表格 | `table` + **TanStack Table 9.3.1** | >200 行走 `react-virtual` 3.14 |
| 图表容器 | shadcn `chart` | 它内部就是 recharts；统一 tooltip/legend/配色 token |
| 关系图 | **Cytoscape.js** 自封装一层（见 §4） | 不要用 d3-force 手绘 |
| 空态 | `empty` | 必须区分三态（`docs/03 §4.1.3`） |
| 代码/日志 | shadcn `code-block` | 2026-10 新增 |
| Agent 运行轨迹 | shadcn `trace` | 2026-10 新增，正好用于"回合记忆栏" |
| 会话/消息流 | `message` + `message-scroller` | 若将来做对话视图 |

### 2.3 状态与数据层

| 用途 | 选择 | 版本 |
|---|---|---|
| 服务端缓存 | `@tanstack/react-query` | 5.107.1 |
| 表格逻辑 | `@tanstack/react-table` | 9.3.1（保守可退 v8） |
| 虚拟滚动 | `@tanstack/react-virtual` | 3.14.26 |
| 客户端状态 | `zustand` | 5.1.0（持久化走 Tauri store，**不用 localStorage**） |
| 表单 | `react-hook-form` + `@hookform/resolvers` | 7.91.0 |
| 校验 | `zod` | 4.6.7 |

## 4 图表：recharts + Cytoscape（**不用一个库硬扛**）

### 4.1 为什么拆成两个（这是本轮最重要的证伪）

用户要求"图表不要自己写"。旧项目只写了"Tremor 停更 / ECharts 359KB"，没有结论。本轮用**类型定义文件**取证：

| 需求 | recharts 3.10.1 能做吗 | 证据 |
|---|---|---|
| 折线/面积/柱/饼 | ✅ | 基础 |
| Sankey / Treemap / Sunburst | ✅ | 有 |
| **力导向网络图（记忆的边）** | ❌ **没有** | `recharts@3.10.1/types/index.d.ts` 里 `Force` / `Graph` / `Chord` / `DependencyGraph` 命中 **0** |

⇒ 想用 recharts 画"记忆之间的关系"，只能自己引 `d3-force` 算坐标再手绘 SVG 线——**正是用户禁止的造轮子**。

而 `echarts@6.1.0` 的类型里明写 `GraphSeriesOption` 且 `layout?: 'none' | 'force' | 'circular'`（`types/dist/shared.d.ts` L11520）。
但整包 **359.3 KB gzip**，只为一张关系图引全量不划算。

### 4.2 最终方案

| 图表类型 | 用什么 | 体积（gzip） |
|---|---|---|
| 趋势/分布/占比/表格内嵌迷你图 | **recharts 3.10.1**（经 shadcn `chart`） | 146.4 KB |
| **记忆关系图（节点+边）** | **Cytoscape.js 3.35.0**（MIT） | 130.6 KB |
| 备选（Plan B） | ECharts 6.1.0（若关系图交互复杂到 Cytoscape 不够用，再评估） | 359.3 KB |
| **不选** | Tremor（npm 停在 2025-01，peer 只写 React ^18，对 React 19 **硬阻塞**）；visx（2026-06 后无推送，且更偏底层拼装）；nivo（2026-07 后无推送）；Chart.js（需另包 wrapper） | — |

**红线特批**：`AGENTS.md` 说"不要引入新的图表库"。**Cytoscape.js 与 recharts 是本条红线的两个例外**，因为它们是"关系图"与"通用图"的两个必要本职；引入第三个图表库必须新 ADR。

### 4.3 配色纪律（图表最容易破坏整体感）

所有图表颜色必须来自 `docs/03 §3.5` 的 token（`--accent` / `--ok` / `--warn` / `--danger` / `--text-*` 的派生色阶），
**禁止**用库自带默认色板。判据：截图取色，所有数据系列颜色都能在 token 里找到来源。

## 5 动效：motion 14.12.0 + auto-animate

| 用途 | 用什么 | 注意 |
|---|---|---|
| 页面/卡片进场、共享元素过渡 | **motion 14.12.0**（原 framer-motion） | MIT；`prefers-reduced-motion` 时全部关闭 |
| 列表增删/重排 | `@formkit/auto-animate` 0.10.2 | 一行接入 |
| 关闭按钮/悬停微交互 | 纯 CSS transition + token 时长 | 不必引库 |

**GSAP 结论（纠正一个常见误解）**：它**已 100% 免费**，但**不是开源**——许可为 Webflow 的 *Standard "No Charge" GSAP License*（含竞争性使用限制与单方修订条款）。
⇒ 既不能说"仍需商业授权"，也不能写进"开源依赖清单"。本项目**不选它**（motion 够用，且 MIT 干净）。

| 能力 | 选择 | 版本 |
|---|---|---|
| 托盘 | `tauri` 的 `tray-icon` feature + 自绘面板（第二 WebView，`tray-panel.html`） | 同 Tauri |
| 单实例 | `tauri-plugin-single-instance` | 2.4.0 |
| 窗口状态记忆 | `tauri-plugin-window-state` | 2.4.1 |

## 9 不选清单（含可点开的理由）

| 不选 | 理由 |
